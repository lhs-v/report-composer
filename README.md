# Report Composer (사내 PC용)

메일로 받은 주간 성과 패키지(zip 여러 통)를 **폴더에 넣기만 하면 자동으로 합쳐 풀고**, 그 안의 글 조각·캡처·영상·결과 페이지를 재료로 골라 **내 페이지를 조립**한 뒤 **Confluence**에 첨부까지 올리는 로컬 도구입니다. Python 표준 라이브러리만 쓰므로 설치할 패키지가 없습니다.

## 설치 (3단계)

1. 이 `composer` 폴더를 사내 PC 아무 곳에나 복사합니다 (예: `C:\Tools\composer`).
2. `composer.config.example.json`을 복사해 `composer.config.json`을 만들고 채웁니다.
   - `inbox_dir`: 메일 첨부 zip을 저장할 폴더 (기본 `~/Downloads/report-inbox`). 없으면 만들어집니다.
   - 페이지 주소가 `…/pages/viewpage.action?pageId=숫자` 형식이면 **Data Center**: `base_url`은 호스트까지(예: `https://confluence.example.com`), `pat`는 프로필 → **Personal Access Tokens**에서 만든 토큰, `email`은 비웁니다. `default_parent_id`는 `pageId=` 뒤 숫자.
   - 페이지 주소가 `…/wiki/spaces/KEY/pages/숫자/제목` 형식이면 **Cloud**: `base_url`은 `/spaces/` 앞까지(`/wiki` 포함, 예: `https://example.atlassian.net/wiki`), `pat`에 id.atlassian.com → 보안 → **API 토큰**, `email`에 Atlassian 계정 이메일. `default_space`는 그 KEY, `default_parent_id`는 `pages/` 뒤 숫자.
   - 사내 인증서로 SSL 오류가 나면 `confluence.ca_bundle`에 사내 CA 인증서 파일(PEM) 경로를 넣습니다.
3. 실행: `python composer.py` → 브라우저가 `http://127.0.0.1:8790`을 엽니다. (창을 닫아도 서버는 터미널이 살아 있는 동안 유지됩니다.)

PowerShell에서 더블클릭 실행을 원하면 바로가기 대상에 `python C:\Tools\composer\composer.py`를 넣으면 됩니다.

## 사용 흐름

1. 메일의 zip 첨부(본문 메일의 `-light.zip`, 후속 메일의 `-part1of3.zip` …)를 `inbox_dir`에 저장합니다. 넣는 대로 3초 안에 풀리고 zip은 `inbox_dir/done/`으로 옮겨집니다. 덜 모였으면 상단에 "자료 2/3 대기 중"이 남아 있고(v0.8.0부터는 이미 온 결과물은 바로 읽을 수 있습니다), 나머지 통을 넣으면 사라집니다.
2. 왼쪽에서 주차를 고르면 가운데 **"보고서 읽기"** 탭에 그 주의 보고서가 **정리 단위 카드**로 나옵니다. 카드마다 추천 여부·종류, 결론을 말하는 제목, 요약, 작업 단위별 문장, 결과(결과 페이지 첫 화면 캡처, 페이지, 파일)가 나오고, "지난주 대비"는 작은 줄로, 근거 작업 단위·응답 발췌·페이지 안 파일은 접혀 있습니다. 부록 단위는 본문 뒤에 모입니다. 주간 개요(weekly.md)도 아래에 이어집니다. 예전(v1) 패키지는 "무엇을 풀려고 했나 → 어떻게 → 대표 결과 → 지금 어디까지 → 다음" 흐름 문서로 나옵니다.
   - 결과 페이지(세션이 만든 HTML)는 "**열어서 집어오기**"로 **가운데 칸에서 보고서 대신 열립니다**("← 보고서로" 또는 Esc로 복귀). 오른쪽 초안은 그대로 보여서 담은 것이 바로 쌓이는 게 보입니다. 두 모니터라면 "새 창"으로 띄워도 같은 초안에 담깁니다.
   - 페이지 안에서 마우스를 올리면 **읽는 단위**가 표시됩니다: 그림·SVG 차트·영상·음성은 붙은 설명과 함께 "그림+설명", 제목이 있는 박스는 "강조 상자", 목록은 "목록 n개", 표는 "표", 소제목은 그 아래 내용까지 "섹션 n개", 그 밖의 글은 "문단". 클릭하면 그 단위가 통째로 초안에 들어가고, 여러 블록이 생기면 **묶음**(함께 이동·삭제, "풀기"로 분리)으로 표시됩니다. Alt+클릭은 한 단계 넓은 구역을 담습니다. **가로로 나란한 칸**(카드 2~4개가 한 줄, 그림+글 좌우 배치 등)은 "가로 n칸" 블록으로 들어가 편집기·미리보기에서도 나란히 보이고, Confluence에는 한 줄짜리 표로 올라갑니다("세로로"를 누르면 풀어 놓습니다). 강조 상자 안의 줄바꿈도 유지됩니다. 담은 직후 "방금 담은 것 취소"로 되돌릴 수 있습니다.
   - 보고서 읽기와 조각 목록은 **프로젝트 → 흐름** 두 단계로 접힙니다(제목 클릭, "모두 접기/펼치기"). 접힌 상태는 브라우저에 기억됩니다.
   - 영상·음성 파일은 읽기 탭에서 바로 재생해 보고 "첨부로 추가"할 수 있습니다.
3. 읽다가 문단·결과·그림에 마우스를 올리면 **＋**가 떠서 초안으로 가져오고, 글을 **드래그해 선택하면 "선택한 글 추가"** 버튼이 떠서 원하는 문장만 가져옵니다. 카드 제목 옆 "흐름 전체 추가"는 제목·요약·문장·캡처를 한 번에 넣습니다(지난주 대비·근거·응답 발췌·페이지 안 파일은 빠지니 필요하면 ＋로 따로 담습니다). "조각 목록" 탭은 같은 재료를 블록 목록으로 보여주며 끌어놓기에 편합니다. 이미 넣은 재료는 "사용됨"으로 표시되고, 여러 주차의 재료를 한 초안에 섞어도 됩니다.
4. 오른쪽 초안에서 글은 그 자리에서 고치고(`**굵게**`, `_기울임_`, `[링크](주소)`), 블록 왼쪽 손잡이(⋮⋮)를 끌거나 ↑↓ 버튼으로 순서를 바꿉니다. Enter로 문단 추가, 빈 문단에서 Backspace로 삭제, Ctrl+Z / Ctrl+Shift+Z로 되돌리기. 모든 변경은 즉시 저장됩니다. 초안은 여러 개 만들고 복제할 수 있습니다.
5. "미리보기"에서 올라갈 모습과 Confluence 저장 형식 원문(검증 결과 포함)을 봅니다.
6. **Confluence에 올리기**: 기본 스페이스·상위 페이지 아래 새 페이지를 만들고, 초안이 참조한 캡처·영상을 첨부한 뒤 본문을 씁니다. 상위 페이지는 제목으로 검색해 바꿀 수 있습니다. 같은 초안을 고쳐 다시 올리면 새 페이지가 아니라 **그 페이지가 갱신**됩니다.
7. **API가 막혀 있을 때(사내 신청 전)**: 두 가지 수동 경로가 있습니다.
   - **서식 복사**: 본문을 그림까지 내장한 서식 있는 텍스트로 복사합니다. Confluence 편집기에 Ctrl+V 하면 글 서식과 그림이 함께 들어갑니다(그림은 첨부로 저장됨). 영상·파일만 따로 첨부합니다.
   - **첨부 폴더**: 초안이 참조한 파일들과 함께 `paste.html`(브라우저로 열어 Ctrl+A, Ctrl+C 하면 위와 같은 효과), `읽어주세요.txt`(순서 안내), `body.html`(API용 저장 형식 원문)이 든 폴더를 만들어 엽니다. 사내 브라우저가 클립보드 서식 복사를 막을 때 이 경로를 씁니다.

## 패키지 형식 v2 (정리 단위, v0.7.0부터)

`outcomes.json`에 `"schema": 2`가 있으면 흐름(streams) 대신 **정리 단위(chapters)** 로 읽습니다. 형식은 저장소의 `docs/package-format-v2.md`를 따르고, `schema`가 없는 예전(v1) 패키지는 지금처럼 그대로 읽힙니다.

- 정리 단위 하나가 흐름 하나처럼 보입니다. 제목 옆에 종류·추천 여부·구역 표시가 붙고, 요약 → 본문 문장 → 결과(캡처·페이지·파일·응답 발췌) 순서로 나옵니다. 부록(`tier: appendix`) 단위는 본문 단위 뒤 "부록" 아래에 모입니다.
- 결과 파일은 폴더 이름이 아니라 `evidence[].package`에 적힌 경로로만 찾습니다. 패키지에 사본이 없는 결과물은 보이지 않습니다.
- "지난주 대비"는 작게 보이고, 근거 작업 단위는 "근거" 아래 접혀 있습니다. 둘 다 "흐름 전체 추가"에 들어가지 않으며, 필요하면 ＋로 따로 담습니다. 조각 목록에서는 흐리게 표시됩니다.
- 한 줄로 접힌 프로젝트(`one_line`)는 그 문장만 흐리게, 작업 단위 목록만 있는 프로젝트(`daily_list`)는 "작업 단위 목록" 하나로 보입니다(패키지에 사본이 있는 결과물도 함께). 한 줄 문장과 프로젝트 개요도 ＋로 담을 수 있습니다. 주간 문서(weekly.md)는 "주간 개요"로 표시됩니다.
- 추천 여부가 "생략"인 정리 단위는 처음에 접혀 있고 흐리게 보입니다.
- 정리 단위의 md 파일은 패키지가 적어 둔 이름(`md`)으로 찾습니다. 같은 주를 다시 받아 예전 파일이 남아 있어도 섞이지 않습니다.
- 조각 id는 `<주차>:<프로젝트>:<정리 단위 id>:<종류>:<n>`입니다. 요약·지난주 대비·근거는 종류 자리에 `lead`·`change`·`units`를, 결과물은 그 정리 단위 결과 목록 안의 순서를 씁니다. 그래서 같은 주를 다시 만들어 보내 요약이 생기거나 사본 하나가 빠져도 나머지 조각의 "사용됨" 표시가 유지됩니다.

## 패키지 형식 v3 (결과물 기록, v0.8.0부터)

`outcomes.json`에 `"schema": 3`과 `records`가 있으면 **결과물 기록** 단위로 읽습니다(저장소의 `docs/package-format-v3.md`). 정리 단위 카드는 v2와 같고, 카드의 결과물이 `records/<프로젝트>/<기록 id>/` 폴더에서 옵니다.

- 결과물 하나가 조각 묶음 하나입니다: 대표 그림(첫 화면 캡처·포스터) → 여는 파일(페이지·문서·그림·영상 720p 사본) → 함께 온 파일(접힘). 조각 id는 `<주차>:<프로젝트>:<정리 단위 id|loose>:<기록 id>:<종류>:<n>`이라 기록 하나가 빠져도 다른 조각의 "사용됨"은 그대로입니다.
- 정리 단위에 들지 않은 결과물은 "정리 단위 밖 결과물"로, 주간 정리 전에 받은 주(정리 단위 없음)는 한 줄 아래 결과물만 보입니다.
- **자료 메일이 다 오지 않아도** 도착한 통부터 풀려 그 안의 결과물은 바로 보이고, 아직 안 온 결과물은 프로젝트 아래 "아직 안 온 결과물 n개: …"로 이름이 나옵니다. 나머지 통을 받은편지함에 넣으면 그 자리에 채워집니다.
- 보낸 쪽이 집에 남긴 파일(큰 부속, 원본 영상)은 카드 아래 "집에 있음"으로 이름만 보입니다. 필요하면 보낸 사람에게 요청합니다.
- **멈춘 장면 담기(v0.8.3부터)**: 결과 페이지 안의 재생 중이 아닌 영상에 마우스를 올리면(또는 일시정지·탐색하면) 영상 위에 "이 장면 담기 (m:ss)" 단추가 뜹니다. 누르면 그 순간의 화면이 그림으로 초안에 들어갑니다(설명: 영상 이름 · 시각). 보고서 읽기 탭의 영상에도 "📷 이 장면 담기"가 있습니다. 담긴 그림은 `weeks/<주차>/picked/`에 저장됩니다.
- **영상 720p 사본(v0.8.2부터)**: 결과 페이지가 `home:영상.mp4`를 가리키는데 같은 폴더에 `영상.720p.mp4`가 와 있으면(2026-10-26 2회차처럼 사본이 함께 온 경우) 페이지를 열 때 그 사본으로 바꿔 재생·집기가 됩니다. 사본이 없는 영상은 그대로 "집에 있음"입니다.
- **추가분(v0.8.1부터)**: 같은 주를 다시 보내면 `<주차>-r2-light.zip`, `<주차>-r2-part1of2.zip`처럼 회차가 붙어 옵니다. 받은편지함에 넣으면 같은 주차 폴더에 덧붙여지고(이미 받은 결과물은 그대로, 새 결과물과 최신 `outcomes.json`만 갱신), "자료 n/N 대기 중"도 회차별로 따로 셉니다. 보낸 쪽이 체크를 뺀 결과물은 화면에서 사라집니다(파일은 폴더에 남음).
- v2·v1 패키지는 지금처럼 읽힙니다.

## Gemini로 다듬기 (v0.8.5부터)

재료를 대충 옮기고 하고 싶은 말만 띄엄띄엄 적어 둔 초안을, 오른쪽 위 **✨ 다듬기** 단추로 Gemini CLI에 맡겨 모든 사람이 읽을 수 있는 글로 다시 씁니다.

- 필요한 것: 사내 PC에 [Gemini CLI](https://github.com/google-gemini/gemini-cli)가 설치되어 있고(`npm i -g @google/gemini-cli`) 한 번 로그인되어 있어야 합니다. PowerShell은 쓰지 않습니다 — 컴포저가 npm의 `gemini.cmd`를 직접 실행합니다(PATH에 없으면 `%APPDATA%\npm\gemini.cmd`도 찾아봅니다). 그래도 "명령을 찾지 못했습니다"가 나오면 `composer.config.json`의 `gemini.command`에 그 전체 경로를 적어 주세요. 명령 이름과 기본 모델은 `composer.config.json`의 `"gemini": {"command": "gemini", "model": "gemini-3.8-flash"}`로 바꿉니다(대화상자에서도 모델을 바꿀 수 있습니다).
- 보내는 것: 초안의 **글만**(제목·문단·목록·표·강조 상자)을 마크다운으로 보냅니다. 그림·파일·영상·가로 칸은 보내지 않고 `[[B:n]]` 자리표시자로 자리만 지켜, 돌아온 글에 원래 자리대로 다시 끼웁니다. 모델이 자리표시자를 빠뜨리면 그 그림은 맨 뒤에 붙습니다(사라지지 않습니다).
- 결과: **새 초안**("원래 제목 · 다듬음")이 생겨 바로 열리고, 원래 초안은 그대로 남습니다. 마음에 안 들면 원래 초안으로 돌아가면 됩니다.
- 문체는 대화상자에서 고릅니다: **개조식(~함/~완료/~예정, 기본)**, 정중한 보고체(~했습니다/~입니다), 평서체(~했다/~이다). 고른 값은 기억됩니다.
- 규칙(프롬프트에 포함): 사실·숫자·고유명사·파일 이름을 바꾸거나 더하지 않음, 고른 문체, 전문 용어는 처음 한 번 풀어 씀, 길이는 원문의 1.5배 이내. "다듬는 방향" 칸에 원하는 어투나 독자를 더 적을 수 있고, 마지막에 쓴 내용이 기억됩니다.
- 오류: 명령을 못 찾으면 설치·PATH를, 모델 이름 오류나 빈 답이면 모델 이름과 로그인을 확인하라는 메시지가 대화상자에 그대로 보입니다. 240초를 넘기면 끊습니다.
- 폴더 신뢰: Gemini CLI 0.39부터 신뢰하지 않은 폴더에서는 비대화식 실행이 종료 코드 55("not running in a trusted directory")로 막힙니다. 컴포저는 자기 작업 폴더(`workspace_dir`)에서 `GEMINI_CLI_TRUST_WORKSPACE=true`로 실행해 이를 넘깁니다. 그래도 같은 오류가 나면 cmd에서 그 작업 폴더로 이동해 `gemini`를 한 번 띄우고 "이 폴더를 신뢰"를 고르면 기록됩니다.

## 결과 페이지는 따로 된 주소에서 열립니다 (v0.7.0부터)

화면과 API는 `http://127.0.0.1:<포트>`, 결과 페이지는 `http://localhost:<포트>`에서 열립니다. 메일로 받은 결과 페이지 안의 스크립트가 초안이나 Confluence 게시 API를 부르지 못하게 주소(출처)를 나눈 것입니다. 페이지에서 조각을 집는 것은 그대로 됩니다. 페이지에서 집은 조각은 가운데 칸이나 그 칸이 연 새 창에 떠 있는 페이지에서 온 것만 받고, 파일은 그 주차 폴더 안의 것만 담깁니다. 회사 PC에서 `localhost`가 열리지 않으면 `composer.config.json`에 `"page_host"`로 다른 이름을 줄 수 있습니다. 127.0.0.1로 가는 호스트 이름이어야 하고(예: `composer-pages.localhost`), IP 주소나 포트를 주면 `localhost`로 되돌립니다.

## 데이터 위치

- 풀린 패키지: `workspace_dir/weeks/<주차>/`
- 초안: `workspace_dir/drafts/*.json` (텍스트라 백업·공유가 쉽습니다)
- 첨부 폴더 내보내기: `workspace_dir/export/<초안 id>/`

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "Confluence가 설정되지 않았습니다" | `composer.config.json`의 `confluence.base_url`, `pat` |
| 401/403 | PAT 만료·권한. 프로필에서 토큰을 다시 발급 |
| SSL/CERTIFICATE 오류 | 사내 CA PEM 경로를 `confluence.ca_bundle`에 지정. 임시로 `verify_ssl: false`도 가능(권장하지 않음) |
| 포트 사용 중 | `python composer.py --port 8795` |
| 주차가 안 풀림 | `inbox_dir` 경로가 설정과 같은지, 조각이 모두 왔는지(`자료 i/N` 메일 전부) |
